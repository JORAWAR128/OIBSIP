# VYORA — Creative Studio Landing Page

A modern, responsive landing page designed for VYORA, a creative studio. The website presents the studio's identity, services, and contact information through a clean layout and a natural, warm color palette.

## About the Project

This project was developed as part of the **OASIS INFOBYTE Web Development and Designing Internship — Level 1, Task 1: Landing Page**.

The goal was to create an attractive and user-friendly landing page using HTML5 and CSS3, with a clear navigation structure, engaging hero section, organized content, and responsive design.

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Features

- Sticky navigation bar with section links
- Hero section with headline, supporting text, and call-to-action
- Services section highlighting the studio's offerings
- About section introducing the creative studio
- Statistics section
- Contact section with relevant links
- Footer with navigation and contact information
- Consistent typography and warm color palette
- CSS animations and hover interactions
- Responsive layout for desktop, tablet, and mobile screens
- Flexbox and CSS Grid for layout organization
