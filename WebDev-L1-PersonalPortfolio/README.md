# Personal Portfolio — S. Jorawar Singh

A personal portfolio website showcasing my profile, technical skills, projects, and contact information. The website is designed with a modern dark theme, muted mustard accents, and a responsive layout.

## About the Project

This project was developed as part of the **OASIS INFOBYTE Web Development and Designing Internship — Level 1, Task 2: Personal Portfolio**.

The objective was to build a professional online portfolio that introduces me, highlights my technical skills and projects, and provides visitors with ways to connect with me.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Personal introduction and profile section
- Profile photo placeholder
- About Me section
- Technical skills section
- Project cards with descriptions and links
- Contact section with email and social links
- GitHub and LinkedIn profile links
- LeetCode profile link
- Resume download link
- Smooth navigation between sections
- Responsive layout for different screen sizes
- Modern dark theme with muted mustard accents
- CSS hover effects and animations
